# Bootstrap 5 Showcase 

Este projeto é um ecossistema web multi-página desenvolvido para demonstrar na prática o poder e a versatilidade do framework **Bootstrap 5**. Ele serve como um guia técnico e visual sobre responsividade, componentes UI e boas práticas de desenvolvimento front-end.

##  Objetivo do Projeto

O objetivo principal é apresentar um layout 100% responsivo que se adapta de forma inteligente a qualquer dispositivo (Mobile, Tablet e Desktop), utilizando exclusivamente as classes nativas do Bootstrap, sem a necessidade de CSS customizado complexo.

##  Tecnologias Utilizadas

*   **HTML5**: Estruturação semântica.
*   **Bootstrap 5.3**: Framework principal para Grid, Flexbox e Componentes.
*   **Bootstrap Icons**: Biblioteca de ícones vetoriais integrada via CDN.
*   **Mobile-First Design**: Metodologia de desenvolvimento focada em dispositivos móveis.

##  Estrutura de Páginas

1.  **Início (index.html)**: Apresentação do projeto e demonstração visual do sistema de Grid.
2.  **Serviços (servicos.html)**: Explicação técnica sobre componentes, utilitários e o ecossistema Bootstrap através de cards interativos.
3.  **Sobre (sobre.html)**: Detalhes sobre a arquitetura do projeto e as vantagens da versão 5 do framework.
4.  **Contato (contato.html)**: Central de conexões profissionais com links diretos para GitHub, LinkedIn e E-mail.

##  Destaques Técnicos

*   **Sistema de Grid Dinâmico**: Uso de breakpoints (`col-12`, `col-md-6`, `col-lg-4`) para reorganização automática do conteúdo.
*   **Zero Custom CSS**: Demonstração de domínio das classes utilitárias do framework para espaçamento, cores e tipografia.
*   **Navegação Responsiva**: Navbar com menu (hambúrguer) otimizado para toque em telas pequenas.
*   **Acessibilidade**: Uso de cores semânticas e estrutura semântica para melhor leitura e navegação.
